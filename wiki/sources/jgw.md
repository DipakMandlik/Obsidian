## Context
This use case outlines how Sun Pharma evaluates Databricks Agent Bricks for building an Enterprise Knowledge Assistant. It targets:
- SOPs (Standard Operating Procedures)
- Batch Manufacturing Records
- Validation & Compliance Documents
- FDA Audit Reports & CAPAs
- Clinical/Laboratory Trials

Using **Agent Bricks**, the supervisor agent uses vector search and document intelligence to answer QA engineer queries (e.g. "Which SOP defines cleaning for Line 3?") without manually searching folders or SharePoint.
